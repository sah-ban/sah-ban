## Selected projects

### 🏋️ TrrackFit

An offline-first Android workout tracker with custom routines, exercise guides, automatic rest timers, and strength and body progress tracking. Log sets, compare previous sessions, and follow personal bests without needing a connection.

Built with React Native and Expo, with native Android workout notifications, background sync, and a Hono API backed by Prisma and PostgreSQL.

[Visit website](https://trrack.fit)

### 🪁 Kite

An open-source Farcaster client with chronological feeds, client filters, profiles, notifications, and account tools. Built with React and TypeScript, with a PostgreSQL-backed feed indexer and direct Snapchain integration. Includes a guide to running your own read node.

[Visit app](https://kite.sahban.dev/) · [Source code](https://github.com/sah-ban/kite)

### 📆 Xchedule

A Chrome extension that makes scheduling posts on X faster. Save preset posting times, select an active slot, and automatically fill the scheduling dialog. Each time slot keeps its own date counter and advances only when you confirm, making it easy to queue posts across multiple days.

[Visit website](https://xchedule.xyz)
